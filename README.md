# aas-core3.2-golang

Go SDK for creating, verifying, and serializing Asset Administration Shell (AAS)
V3.2 models as JSON and XML. Requires **Go 1.19 or later**.

This SDK is under development, and full validation is still pending.

## Installation

Once the SDK is available upstream, install it from your application's Go module:

```sh
go get github.com/chris-koo/aas-core3.2-golang
```

## Usage

This example creates and verifies a model, then serializes it to JSON:

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"

	aasjsonization "github.com/eclipse-aascw/aas-core3.2-golang/jsonization"
	aastypes "github.com/eclipse-aascw/aas-core3.2-golang/types"
	aasverification "github.com/eclipse-aascw/aas-core3.2-golang/verification"
)

func main() {
	property := aastypes.NewProperty(aastypes.DataTypeDefXSDString)
	idShort := "greeting"
	property.SetIDShort(&idShort)
	value := "Hello from AAS V3.2"
	property.SetValue(&value)

	submodel := aastypes.NewSubmodel("https://example.com/submodels/greeting")
	submodel.SetSubmodelElements([]aastypes.ISubmodelElement{property})

	environment := aastypes.NewEnvironment()
	environment.SetSubmodels([]aastypes.ISubmodel{submodel})

	var firstViolation *aasverification.VerificationError
	aasverification.Verify(environment, func(err *aasverification.VerificationError) bool {
		firstViolation = err
		return true
	})
	if firstViolation != nil {
		log.Fatal(firstViolation)
	}

	jsonable, err := aasjsonization.ToJsonable(environment)
	if err != nil {
		log.Fatal(err)
	}
	data, err := json.MarshalIndent(jsonable, "", "  ")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(string(data))
}
```

For API details, see [types](types/), [verification](verification/),
[jsonization](jsonization/), and [xmlization](xmlization/), or run
`go doc` on the corresponding package.

## Generation

The SDK is generated from
[aas-core-meta](https://github.com/eclipse-aascw/aas-core-meta)'s
`aas_core_meta/v3_2.py` using
[aas-core-codegen commit 65f50394](https://github.com/eclipse-aascw/aas-core-codegen/commit/65f503944140a57a8109d0262bac9cab029f1662).
Changes to generated behavior should be made in codegen and regenerated here.
